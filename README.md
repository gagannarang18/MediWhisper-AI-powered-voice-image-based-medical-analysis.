# 🩺 MediWhisper

**AI-powered voice & image-based medical diagnostic assistant**  
Built with **gTTS**, **ElevenLabs**, **Groq**, and **Gradio**

---

## 🚀 Overview

**MediWhisper** is a multimodal AI system designed for intelligent medical analysis. It allows users to **speak symptoms**, **upload medical images**, or **submit test reports**, and receive AI-generated diagnoses and suggestions — delivered in both **text** and **voice** formats.

Whether you're a healthcare professional or an individual seeking insight, MediWhisper brings accessible, voice-enabled diagnostics to your fingertips.

---

## 🧠 Key Features

- 🎙️ **Voice Input**: Speak symptoms and questions using a mic — powered by **SpeechRecognition** and **PyAudio**
- 🖼️ **Image Analysis**: Upload X-rays, scans, or test reports for AI-based interpretation
- 📢 **Dual Output**: Receive responses in **text** and **natural-sounding voice** using **gTTS** or **ElevenLabs**
- ⚡ **Groq Acceleration**: Ultra-fast inference with **Groq LLMs**
- 🎛️ **Gradio Interface**: Simple, intuitive UI for interaction

---

## 🛠️ Tech Stack

- **gTTS / ElevenLabs** – Text-to-speech generation
- **SpeechRecognition + PyAudio** – Voice input handling
- **Groq** – Fast LLM-powered medical reasoning
- **Gradio** – Web interface
- **Pydub, fsspec** – Audio conversion and streaming support
- **Python**

---

## 🧪 Use Cases

- Quick AI-assisted symptom checks  
- Voice-based medical Q&A  
- AI interpretation of X-rays, scans, and test values  
- Accessibility-friendly tool for patients with vision or reading challenges
